# Faculty Initials Glossary — resolve every abbreviation in the timetable grids

Every uppercase token found in the class-timetable grids, matched against
the published rosters (`02-departments/*/faculty.md`) and the signature /
class-in-charge lines inside the timetable PDFs themselves.

**How to use:** a grid cell like `Lab DBMS A1 A2 VK RB 305` = DBMS lab,
batch groups A1+A2, faculty **VK** + **RB**, room 305. Look the initials up
in the table below.

Confidence: **HIGH** = explicit PG legend or exact roster initial ·
**MED** = matches a roster name's initials · **LOW** = only found in a
signature/in-charge line · **?** = unresolved (part-time/visiting, or an
initial shared by several names — check the roster for context).
